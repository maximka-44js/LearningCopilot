# Markdown

## MDX

With Nextra, all `.mdx` files under the `content` directory are rendered with
[MDX](https://mdxjs.com/about). It supports Markdown plus React components.

For example:

```mdx
## Hello MDX

import { useState } from 'react'

export function Counter({ children }) {
  const [count, setCount] = useState(0)
  return (
    <button onClick={() => setCount(prev => prev + 1)}>
      {children}
      {count}
    </button>
  )
}

<Counter>**Clicks**: </Counter>
```
