# Docs Theme

Nextra Docs Theme includes almost everything you need for a modern documentation website:

- a top navigation bar
- a search bar
- a pages sidebar
- a table of contents (TOC)
- and other built-in components

> This website section is powered by Nextra in App Router mode.

## Install

If Next.js is already installed, add only the docs dependencies:

```bash
npm i nextra nextra-theme-docs
```
