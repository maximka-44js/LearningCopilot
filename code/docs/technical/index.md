# Техническая документация

## Компоненты

- **Backend** — REST API на Fiber.
- **Frontend** — веб-интерфейс на Next.js.
- **Авторизация** — Keycloak и OIDC.
- **База данных** — PostgreSQL с расширением pgvector.
- **Файлы** — S3-совместимое объектное хранилище.
- **Фоновые задачи** — River Queue.

## Локальный запуск

Перейдите в каталог `backend`, скопируйте пример окружения и запустите
development-стек:

```sh
cd backend
cp .env.dev.example .env.dev
make dev-up
```

После запуска:

- приложение доступно по адресу `http://frontend.lvh.me`;
- проверка состояния API — `http://app.lvh.me/healthz`;
- Swagger — `http://app.lvh.me/swagger/`.

Для остановки окружения выполните:

```sh
make dev-down
```

## Структура репозитория

- `backend/` — API, фоновые задачи, миграции и Docker-окружение;
- `frontend/` — пользовательский интерфейс;
- `docs/` — этот сайт документации VitePress.

Описание продукта, пользовательские сценарии и отчёт размещаются в корне
репозитория и не дублируются в технической документации.
