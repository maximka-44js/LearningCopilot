# Помощь

## Вход в систему

1. Откройте страницу входа и нажмите **Continue**.
2. Введите данные учётной записи в окне Keycloak.
3. После успешного входа откройте нужный раздел в верхнем меню.

Если вход не выполнен, проверьте данные учётной записи. При истёкшей сессии
приложение предложит войти заново.

## Проекты

В разделе **Projects** можно:

- создать проект с названием, описанием, приоритетом и дедлайном;
- открыть карточку проекта и посмотреть его прогресс;
- изменить параметры проекта в **Project settings**;
- удалить проект после подтверждения действия.

Название проекта обязательно. Дедлайн должен быть корректной датой.

## Этапы и задачи

Внутри проекта откройте **Stages**, чтобы создать этап с названием, целью,
порядком и необязательным дедлайном.

На странице этапа можно создать задачу. Укажите ожидаемый результат, сложность
от 1 до 10, приоритет и распределение частей между пониманием, запоминанием и
практикой. Хотя бы одна часть задачи должна быть больше нуля.

Ошибки формы не закрывают её: исправьте подсвеченные данные и повторите
сохранение.

## Оценка готовности

Откройте задачу и выберите **Record assessment**. Выберите блок:
`comprehension`, `memorization` или `practice`, затем укажите самооценку от 0
до 100 и сохраните её.

На странице задачи также можно изменить веса блоков и допустимый статус задачи.
Сумма частей для весов должна быть больше нуля.

## Анализ прогресса

Дашборд проекта показывает readiness, coverage, дедлайн, приоритет, риск и
этапы, которые требуют внимания. Блок **Critical to deadline** помогает найти
задачи, способные повлиять на достижение цели.

После сохранения оценки обновите дашборд, если показатели ещё не изменились.

## Библиотека материалов

В разделе **Storage** можно:

1. создать библиотеку и выбрать её видимость;
2. для приватной библиотеки добавить пользователей с ролями `reader` или
   `writer`;
3. открыть дерево файлов;
4. создать папку;
5. загрузить файл поддерживаемого типа размером до 500 МБ;
6. выбрать файл или папку и удалить их после подтверждения.

Для загрузки файлов требуется право записи. Если файл не поддерживается или
превышает лимит, исправьте выбор и повторите загрузку.

## Политики проекта

В настройках проекта откройте раздел политик, измените нужные пороги и веса и
сохраните раздел. Значения должны находиться в допустимых диапазонах, которые
указаны рядом с полями.

## API keys

В разделе **API keys** можно создать ключ, выбрать его область доступа и
удалить ключ после подтверждения. Секрет ключа показывается только при создании:
сохраните его сразу и не публикуйте в отчётах, скриншотах или репозитории.

## Если произошла ошибка

Сообщение об ошибке содержит безопасную причину и рекомендуемое действие:

- проверьте введённые данные для ошибок валидации;
- повторите запрос при временной ошибке сервиса;
- обновите страницу, если объект был изменён в другом окне;
- войдите заново, если сессия истекла;
- убедитесь, что у вас есть права доступа к библиотеке или проекту.

Введённые данные в формах сохраняются при ошибке. Технические сведения,
секреты, токены и внутренние пути приложения пользователю не показываются.
