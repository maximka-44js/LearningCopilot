## 1. Действие: регистрация и первый вход в систему

**Сценарий:**
1. Пользователь открывает веб‑приложение и нажимает кнопку "Регистрация".
2. Система открывает форму регистрации через единый сервис входа.
3. Пользователь заполняет форму (email и пароль) и подтверждает регистрацию.
4. Система проверяет корректность данных и показывает ошибки при необходимости.
5. При успешной регистрации система создаёт учётную запись и возвращает пользователя в приложение.
6. Пользователь входит в систему и попадает на страницу проектов.
7. Система предлагает создать первый проект — главную цель.
8. Пользователь задаёт имя проекта и краткую цель (например, "Подготовка к экзамену по матану").
9. Система создаёт проект и предлагает добавить первый стейдж (этап).


## 2. Действие: создание новой библиотеки конспектов

**Сценарий:**
1. Пользователь открыет раздел "Библиотеки".
2. Пользователь нажимает "Создать библиотеку".
3. Система показывает форму: название, описание и тип доступа.
4. Пользователь вводит название и при необходимости добавляет описание.
5. Пользователь выбирает режим доступа: "приватная" или "публичная".
6. Для приватной библиотеки пользователь добавляет контрибьюторов по нику.
7. Пользователь назначает права контрибьюторам (просмотр/редактирование).
8. Система проверяет корректность введённых данных и показывает результат добавления.
9. Пользователь подтверждает создание; библиотека доступна для прикрепления к проектам и стейджам.


## 3. Действие: загрузка учебного материала

**Сценарий:**
1. Пользователь открыет нужную библиотеку.
2. Пользователь нажимает "Загрузить материал".
3. Система предлагает выбрать файл (txt, md, pdf или изображения) и ввести название.
4. Пользователь выбирает файл и подтверждает загрузку.
5. Система проверяет формат и доступность файла.
6. Если файл не подходит, система показывает причину и предлагает выбрать другой.
7. Если файл подходит, система добавляет материал в библиотеку и подготавливает его для использования.
8. Система показывает статус и теги/метаданные.
9. Пользователь видит документ в списке

## 4. Действие: создание нового проекта

**Сценарий**
1. Пользователь логинится и попадает на главный экран с меню
2. Пользователь заходит на страницу проектов, где он видит список текущих проектов с их метрики
3.Пользователь нажимает кнопку создания проекта
4. Пользователь заполняет форму с необходимой  информацией о проекте
5. Пользователь пользователь подтверждает действие и если данные корректны, проект создаётся.
6. Проект появляется в списке

## 5. Действие: редактировать и настроить проект

**Сценарий**
1. Авторизованный пользователь заходит на страницу проектов
2. Пользователь выбирает нужный проект и кликать на него, перед ним открывается дашборд проекта
3. С этого экрана по кнопке редактирования он  попадает на модалку редактирования основной информации и с разделов для тонкой настройки( политика проекта)
4. Пользователь редактирую основную информацию 
5. Пользователь кликает на раздел с тонкой настройкой
6. После редактирования он сохраняет изменения по кнопке.
7.Пользователь попадает обратно на дашборд проекта
8.Пользователь может скролить страницу и обозревать его метрики, рекомендуемые действия
9.Пользователь также может удалить проект по кнопке и окну с подтверждением действия, где надо вписать название проекта

## 6. Действие: создать стейдж

**Сценарий**
1. Пользователь авторизуется
2. Пользователь переходит в раздел проектов по меню
3. Пользователь выбирает нужный проект, для этого на странице есть поиск и фильтрация
4. Пользователь переходит на него и попадает на дашборд, там он видит раздел блок stages с ссылкой на список стейджей,он кликать на него
5. Пользователь попадает на раздел stages для  конкретного проект
6. Пользователь нажимает на кнопку создания нового стейджа
7. Пользователь заполняет модалку с формой 
8. Пользователь нажимает кнопку создания, если данные корректны то он возвращается на экран со списком стейджей
9.Пользователь создал стейдж и может видеть
его в списке, он также может перейти на его дашборд

## 7. 
Действие: создать задачу
1. Пользователь авторизуется
2. Пользователь переходит через главное меню на раздел проектов
3. Пользователь переходит в нужный проект
4. Пользователь переходит в нужный стейдж
5. Пользователь кликает на раздел задач
6. Пользователь попадает на экран с задачами
7. Пользователь нажимает кнопку создания задачи 
8. Пользователь заполняет форму создания задачи
9. Пользователь кликать кнопку сохранения, если всё корректно, задача создаётся, модалка закрывается, задача созданна
